# Minesweeper-CPP
A Simple Minesweeper Game that uses C++ and SFML library.

**The Main Menu**

Main Menu Interface: Custom-built interactive UI featuring state management, hover effects, and custom font rendering using the SFML graphics module.

<img width="476" height="512" alt="swappy-20260427-203354" src="https://github.com/user-attachments/assets/0a3948b8-0d2d-446d-a391-60e0a9566c38" />


**Difficulty Selection**

Dynamic Difficulty Selection: Allows users to choose between Beginner, Intermediate, and Expert modes, which dynamically re-allocates memory and scales the grid size and mine density at runtime.

<img width="486" height="518" alt="swappy-20260427-203405" src="https://github.com/user-attachments/assets/263b2acf-bb06-4290-a6ff-7c34b350f2bb" />


**Starting a New Game**

Game Initialization: A clean, retro-style grid generation featuring a dynamic real-time session timer and active window event polling.

<img width="481" height="515" alt="swappy-20260427-203417" src="https://github.com/user-attachments/assets/e8a6dc4c-3e10-4d6d-80d4-596560e375eb" />


**Active Gameplay:**

Core Gameplay Mechanics in Action: Demonstrates complete implementation of Minesweeper logic, including tile flagging (red '?' blocks), proximity number calculation, and the recursive "flood-fill" algorithm to instantly clear empty adjacent spaces.
