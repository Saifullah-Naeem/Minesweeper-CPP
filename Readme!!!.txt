How to play the game

1.Use Up and Down Arrow key to traverse the options.

2.Use Enter key to select the highlighted option,

3.Press ESC key to go back to previous Menu.

4.When in game use Left Mouse Click to reveal the tile and Right Mouse Click to place a flag on it.

5.When you win or lose the game press Enter key to go back to the Main Menu.



User can Turn Music On or Off in the option menu by just simply pressing the Enter Key
  Green is for unmuted music and Red is for Muted Music

Enjoy!
